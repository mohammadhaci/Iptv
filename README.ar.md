# OwnTV — مشغّل IPTV لأجهزة Fire TV و Android TV 📺

<p align="center">
  <img src="extras/logo.png" alt="OwnTV" width="300">
</p>

هذا المستودع نسخة من مشروع [OwnTV](https://github.com/ahXN00/OwnTV) مفتوح المصدر (رخصة GPLv3) —
مشغّل IPTV مصمَّم خصيصًا للتلفزيون والريموت، ويدعم اشتراكات **Xtream Codes** وقوائم **M3U**.

> ⚠️ التطبيق **مشغّل فقط** — لا يوفّر أي قنوات أو اشتراكات. أنت تضيف اشتراكك الخاص (Xtream أو M3U).

---

## ✨ ليش هذا المشغّل؟

| المطلوب | الموجود |
|---------|---------|
| **جودة 4K** | مسار عرض مباشر (zero-copy) لـ 4K HDR مع فك تشفير عتادي (Hardware Decoding) |
| **السرعة وعدم التقطيع** | محرّكان للتشغيل: **ExoPlayer** للبث المباشر (تشغيل شبه فوري لـ HLS) و **libmpv/FFmpeg** للأفلام والمسلسلات (توافق أقصى مع كل الصيغ) + إعادة اتصال تلقائية عند انقطاع البث |
| **تقسيم القنوات** | أقسام Live TV / أفلام / مسلسلات، عمود تصنيفات كامل، مفضّلة وسجلّ مشاهدة لكل قسم، إخفاء/إعادة تسمية/ترتيب التصنيفات، قفل PIN |
| **Fire TV** | واجهة مبنية للتلفزيون والريموت (D-pad) من الأساس، ويدعم Android 8 وأحدث |
| **دليل قنوات EPG** | شبكة برامج XMLTV + مشاهدة ما فات (Catch-up حتى 7 أيام) + إرجاع البث المباشر (Timeshift) |
| **إضافات** | بروفايلات متعددة مع قفل للأطفال، تحميل الأفلام للمشاهدة بدون نت، بحث شامل، ملصقات وقصص الأفلام من TMDB، تحديث تلقائي للتطبيق |

## 📥 التثبيت على Fire TV (خطوة بخطوة)

### 1. فعّل التثبيت من مصادر خارجية
- من الشاشة الرئيسية: **Settings ← My Fire TV ← Developer Options**
- فعّل **Apps from Unknown Sources** (أو **Install unknown apps** واختر تطبيق Downloader)
- إذا ما ظهرت Developer Options: روح على **Settings ← My Fire TV ← About**، وانقر على اسم الجهاز 7 مرات

### 2. نزّل تطبيق Downloader
- من متجر أمازون، نزّل تطبيق **Downloader** (البرتقالي، من AFTVnews)

### 3. نزّل OwnTV
- افتح Downloader واكتب هذا الرابط:

```
https://github.com/mohammadhaci/Iptv/releases/latest/download/OwnTV.apk
```

- بعد التنزيل اضغط **Install** ثم **Open**

> 💡 التطبيق فيه **محدّث داخلي** — أي إصدار جديد بيوصلك إشعار فيه وبتحدّث بضغطة زر، بدون ما تعيد الخطوات.

## 🔑 إضافة اشتراك Xtream

عند أول تشغيل (أو من **Settings ← Sources**):

1. اختر **Add Source ← Xtream Codes**
2. أدخل بيانات اشتراكك الثلاثة (بيعطيك ياها مزوّد الخدمة):
   - **Server URL** — رابط السيرفر مع المنفذ، مثال: `http://example.com:8080`
   - **Username** — اسم المستخدم
   - **Password** — كلمة المرور
3. اضغط حفظ — رح يبدأ سحب القنوات والأفلام والمسلسلات (الاستيراد بالأولوية: بيجهّز Live TV أولًا والباقي بيكمل بالخلفية)
4. دليل القنوات (EPG) بينسحب تلقائيًا من نفس اشتراك Xtream

> التطبيق مبني ليتحمّل الاشتراكات الضخمة (~50 ألف قناة و~168 ألف فيلم) بدون تهنيق.

## ⚙️ إعدادات مهمة لأفضل جودة وسرعة

- **فك التشفير العتادي (Hardware Decoding)** — مفعّل افتراضيًا من **Settings ← Video Player**، خلّيه مفعّل لتشغيل 4K بسلاسة
- **قناة بتقطّع أو ما بتشتغل؟** — أثناء التشغيل اضغط على زر **MPV/EXO** لتبديل محرّك التشغيل لهذه القناة (بينحفظ الاختيار لكل قناة لحال)
- **الصوت المحيطي (Surround Sound)** — إذا عندك مسرح منزلي فعّله من **Settings ← Video Player** (Dolby/DTS)
- **HDR** — بيشتغل تلقائيًا إذا كانت شاشتك تدعمه
- **الشبكة** — للبث بجودة 4K يفضَّل واي فاي 5GHz أو وصلة إيثرنت (محوّل شبكة لـ Fire TV Stick)؛ سرعة 25Mbps وما فوق مثالية
- **التحديث التلقائي للقوائم** — من **Settings ← Content ← Auto refresh** حدّد كل قديه يعيد سحب القنوات من السيرفر

دليل الاستخدام الكامل والاختصارات المخفية (بالإنجليزية): [**USER_GUIDE.md**](extras/USER_GUIDE.md)

## 🎮 اختصارات الريموت المهمة

| الزر | الوظيفة |
|------|---------|
| **ضغطة مطوّلة على OK** (على أي قناة/فيلم) | قائمة سريعة: مفضّلة ⭐ / إعادة تسمية / إخفاء / ترتيب / ربط EPG / مشاهدة ما فات |
| **سهم يسار** (داخل المشغّل والأزرار مخفية) | قائمة القنوات فوق البث — بدّل قناة بدون ما تطلع من ملء الشاشة |
| **CH+ / CH−** أو **فوق/تحت** | تنقّل بين قنوات نفس التصنيف (zapping) |
| **زر ⇄ MPV/EXO** (من أزرار المشغّل) | تبديل محرّك التشغيل للقناة الحالية — الحل السحري لأي قناة معاندة |
| **زر ⓘ Info** | معلومات البث الحية: الدقة · fps · HDR · البترة (bitrate) · نوع فك التشفير |
| **زر Audio** | اختيار مسار الصوت + ضبط تزامن الصوت مع الصورة (A/V sync) |

💡 بقائمة القنوات، جنب كل قناة بيظهر **دقة البث الحقيقية** (مثلًا 1080p أو 4K) — فما في قناة مكتوب عليها 4K وهي بالحقيقة أقل بتضحك عليك.

## 🔧 حل المشاكل الشائعة

- **قناة 4K بتقطّع أو فيها تشويش؟** افتح أزرار المشغّل واضغط زر **⇄ MPV/EXO** — بينتقل لمحرّك التشغيل الثاني وبيتذكّر اختيارك لهالقناة دائمًا. هذا بيحل أغلب مشاكل التقطيع والتشويش.
- **صوت بدون صورة (شاشة سوداء)؟** التطبيق بيكتشفها لحالو وبيبدّل المحرّك تلقائيًا — انطر ثواني.
- **الاشتراك ما عم يتصل؟** تأكد إن الرابط بصيغة `http://server:port` بالضبط متل ما بعتو المزوّد (بدون `/` بالآخر عادةً)، وإن الاشتراك مش منتهي أو مستخدم على أجهزة أكثر من المسموح.
- **دليل القنوات (EPG) فاضي؟** روح على **Settings ← EPG Sources**، احذف المصدر وأعد إضافته وسوّي Sync من جديد.
- **الجهاز ضعيف (Fire TV Stick قديم بذاكرة 1-2GB)؟** أوقف الحركات من **Settings ← Animations**، وخلّي UI Zoom على 100% أو أعلى، وأوقف Live Preview إذا لزم.
- **الصوت مش متزامن مع الصورة؟** من أزرار المشغّل: **Audio ← A/V sync** وعدّل بخطوات ±50ms حتى يتطابق.

## 🌐 موقع التحميل + تطبيق الايفون

المستودع ينشر تلقائيًا موقعًا على GitHub Pages (مجلد `site/`):

- **صفحة التحميل**: <https://mohammadhaci.github.io/Iptv/> — افتحها بتطبيق Downloader على Fire TV واضغط زر التحميل
- **تطبيق الايفون (ويب)**: <https://mohammadhaci.github.io/Iptv/app/> — مشغّل Xtream خفيف يعمل بالمتصفح: قنوات مباشرة + أفلام + مسلسلات + مفضلة، ويُثبَّت على الشاشة الرئيسية (Safari ← زر المشاركة ← **Add to Home Screen**)

> **ملاحظة للايفون:** Safari يمنع تشغيل بث `http` من صفحة `https` (mixed content). إذا سيرفر
> اشتراكك ما بيدعم https، استضف الموقع على نطاقك عبر http أو استخدم بروكسي CORS من
> الإعدادات المتقدمة بشاشة الدخول. الأفلام بصيغة MKV غير مدعومة على الايفون (قيود Safari نفسها).

### ربط الموقع بسبدومين على استضافتك (Hostinger)

طريقتان — اختر الأسهل لك:

**أ. توجيه DNS إلى GitHub Pages (يبقى الموقع يتحدث تلقائيًا):**
1. من hPanel: **Domains ← DNS / Name Servers**
2. أضف سجل **CNAME**: الاسم `tv` (أو أي اسم سبدومين تريده) → القيمة `mohammadhaci.github.io`
3. من GitHub: **Settings ← Pages ← Custom domain** واكتب `tv.yourdomain.com` وفعّل **Enforce HTTPS**

**ب. رفع الملفات مباشرة على Hostinger:**
1. من hPanel أنشئ السبدومين (**Domains ← Subdomains**)
2. نزّل مجلد `site/` من هذا المستودع وارفع محتواه لمجلد السبدومين عبر File Manager
3. (لهذه الطريقة يلزم إعادة الرفع يدويًا عند أي تحديث)

## 📦 نسختك الخاصة عالتلفزيون: OwnTV+

هذا المستودع بيبني **نسخة خاصة** من التطبيق اسمها **OwnTV+**:

- معرّف تطبيق مختلف (`tv.own.owntv.plus`) — بتنزل **جنب** نسخة OwnTV الأصلية بدون أي تعارض
- المحدّث الداخلي فيها بيتابع **إصدارات هذا المستودع** (مش المشروع الأصلي)
- رابط التثبيت عبر Downloader على Fire TV:

```
https://github.com/mohammadhaci/Iptv/releases/latest/download/OwnTV.apk
```

### دورة التحديث الكاملة (تلقائية)

1. المطوّر الأصلي يصدر نسخة رسمية جديدة (مثلًا v4.2.0)
2. المزامنة الأسبوعية (`Sync upstream`) تسحب الكود الجديد **وتنشئ نفس الـ tag هنا تلقائيًا**
3. الـ CI يبني إصدار OwnTV+ موقّعًا وينشره بصفحة [إصدارات هذا المستودع](https://github.com/mohammadhaci/Iptv/releases)
4. OwnTV+ المثبّت عالتلفزيون يكتشف الإصدار ويعرض التحديث بضغطة زر

وتقدر تسرّع الدورة بأي وقت: **Actions ← Sync upstream (OwnTV) ← Run workflow**.

### شرط التشغيل الوحيد (مرة واحدة): أسرار التوقيع

حتى تكون الإصدارات موقّعة بمفتاح ثابت (وبالتالي التحديثات تتركب فوق بعضها بدون حذف)، لازم تضيف 4 أسرار
بـ **Settings ← Secrets and variables ← Actions**: `KEYSTORE_BASE64` و`KEYSTORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD`.
(بدونها الـ CI يبني نسخ debug بتوقيع عشوائي — بتشتغل بس كل تحديث يتطلب حذف وإعادة تثبيت.)

- أي push بيبني كمان APK تجريبي بتلاقيه بقسم **Artifacts** بصفحة [Actions](https://github.com/mohammadhaci/Iptv/actions)
